<p>Godlo は <a href="https://github.com/yt-dlp/yt-dlp">yt-dlp</a>、<a href="https://github.com/mikf/gallery-dl">gallery-dl</a>、<a href="https://pypi.org/project/getjmanga/">getjmanga</a> を端末上で動かし、保存したものを一覧・閲覧・再生できるアプリです。ツールは再実装ではなく本物の Python パッケージなので、PC と同じサイトに対応します。</p>

<p><b>ダウンロード</b></p>
<ul>
<li>URL を貼り付けるか、ブラウザなどのアプリから共有します。どのツールが扱えるか、動画・音声・画像のどれかを自動で判定します。</li>
<li>yt-dlp: 動画（画質を選択）または音声（形式を選択）、再生リスト全体。</li>
<li>gallery-dl: 対応サイトの画像。</li>
<li>getjmanga: 漫画の話（前後の話も）、CBZ 出力にも対応。作品を「巡回」に登録すると、後で新しい話を取得します。</li>
<li>ダウンロードは進捗通知付きでバックグラウンドで 1 件ずつ実行します。</li>
</ul>

<p><b>ライブラリ</b></p>
<ul>
<li>画像・音声・動画のタブで、保存先にあるものをサイト別、さらに作品・ユーザー・再生リスト別に一覧します。</li>
<li>ほかのアプリが追加・削除したファイルも反映します。</li>
</ul>

<p><b>リーダーとプレイヤー</b></p>
<ul>
<li>漫画・画像リーダー: 右から左、左から右、縦スクロール。単ページと見開きに対応。</li>
<li>バックグラウンド再生できる音声プレイヤーと、ピクチャー・イン・ピクチャー対応の動画プレイヤー。</li>
</ul>

<p><b>その他</b></p>
<ul>
<li>yt-dlp・gallery-dl・getjmanga はアプリを更新せずに設定画面から更新できます。</li>
<li>ツールの設定ファイル（gallery-dl.conf、getjmanga.toml、cookies.txt）は Download/Godlo/.config/ から読み込みます。</li>
<li>英語と日本語の UI、ライト・ダークテーマ、ダイナミックカラー。</li>
</ul>

<p>ツールが Download/Godlo/ に通常のファイルパスで書き込むため、「すべてのファイルへのアクセス」権限を求めます。対応するのは arm64-v8a と x86_64 の端末のみです。</p>
